# MemOS MCP

A FastMCP server providing memory management and context bridge capabilities for the OmegaKG ecosystem.

## Quick Start

See [BUILD.md](BUILD.md) for detailed build and run instructions.

## Features

- **Memory Storage**: Store and retrieve memory fragments with tags
- **Vector Search**: Semantic search across memories using Qdrant
- **Knowledge Graph**: Neo4j integration for relationship tracking
- **Multi-Database**: Support for SQLite, PostgreSQL, and Neo4j
